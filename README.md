# androidtv-playlist

Автоматически собираемый IPTV-плейлист: скрипт скачивает плейлисты из нескольких
открытых источников, дедуплицирует каналы, проверяет живость каждого потока
(HLS-манифест) и публикует единый плейлист на GitHub Pages.

**Подписка в IPTV-плеере (Televizo/TiviMate и т.п.):**

```
https://<username>.github.io/androidtv-playlist/playlist.m3u8
```

## Как это работает

1. [playlist_builder.py](playlist_builder.py) читает [sources.yaml](sources.yaml)
   (порядок = приоритет: дубль канала отбрасывается в пользу более раннего источника).
2. Каждый поток проверяется двумя попытками (HTTP 200 + содержимое похоже на HLS/поток,
   HTML-заглушки считаются мёртвыми). Мёртвые удаляются, статистика пишется в stats.json.
3. Сортировка: впереди эфирные мультиплексы РФ (№1–10, №11–20) и Чаваш ЕН (№21) —
   список настраивается в `fixed_order`; каналам проставляется `tvg-chno`.
4. Телепрограмма (EPG): скрипт сопоставляет каналы с XMLTV-источником
   ([teleguide.info](https://www.teleguide.info/download/new3/xmltv.xml.gz)) по нормализованным
   именам и переписывает `tvg-id` под ID EPG; ссылка добавляется в заголовок `x-tvg-url`.
5. GitHub Actions запускается ежедневно (05:00 UTC / 08:00 МСК) и при изменениях
   коммитит `dist/` и публикует его на Pages.
6. Плеер на приставке подписан на постоянный URL — обновления подхватываются
   автоматически (при переподключении плейлиста).

## Подключение телепрограммы в плеере

Большинство плееров подхватывают EPG из заголовка плейлиста автоматически. Если нет —
в настройках плейлиста укажите EPG-URL вручную:

```
https://www.teleguide.info/download/new3/xmltv.xml.gz
```

## Локальный запуск

```bash
pip3 install pyyaml
python3 playlist_builder.py sources.yaml dist
# результат: dist/playlist.m3u8, dist/stats.json
```

## Добавить источник

Добавить запись в [sources.yaml](sources.yaml) (URL плейлиста m3u/m3u8) — на следующий
запуск канал появится в общей сборке. Канал дублируется? Источник выше в списке побеждает.
